How judges score it

  • Impact, 30%: make early housing exploration useful to people without a large development team. Show a concrete next step, not an unmeasured promise of homes delivered.
  • Meta AI tooling, 25%: show a multi-step research and architectural tool loop, editable outputs, image selection and visual communication.
  • Technical depth and execution, 20%: demonstrate stable geometry, revisions, IFC/Pascal exchange and the Blender rendering pipeline.
  • Demo, 25%: a working product, clear before-and-after edit, coherent visual sequence and accessible live experience.

Stage one checks viability, theme fit and meaningful use of Meta Model API or Meta open-weight models during the event. The top five per track advance to the final round under the same rubric.

From intent to a building you can inspect

Housing goal → Muse Spark and sourced research → editable plan and massing → Pascal / IFC → Blender and GLB → interactive walkthrough

Muse Spark can reason over the request, choose registered tools and use their returned evidence to continue. Arosa’s code calculates geometry and validates plan changes. Pascal connects the editable scene to the plan. The Blender/Bonsai worker builds an editable scene and rendered artifacts from plan-derived IFC. Three.js presents the result interactively.

This is useful because the user can move between an idea, a drawing and a spatial experience without manually coordinating every software step. The professional tools already existed. AI makes a natural-language orchestration layer practical; it does not replace the survey, engineering or approval process.

Computer use and Blender

Meta documents Muse Spark computer use, and Muse Code’s Blender capabilities. Arosa’s current worker uses background Blender scripts, not autonomous desktop clicks. The demonstration can show real agent tool calls, plan fidelity, Blender artifacts and the walkthrough today. A separate desktop-control claim needs a recorded Meta-driven Blender session and saved output.

For that session, open the plan-derived scene, ask Meta to improve a material or light without moving walls or openings, inspect the rendered result, and compare plan measurements before and after.
