# Contributions and source provenance

## Project scope and timeline

Arosa Hackathon Launch is the full Arosa startup application for the Meta Global AI Developer Hackathon, Startups track, Build for Your World.

Michael Ort identifies October 29, 2026 as the start of the current startup build, following a landing-page-only stage. He identifies the earlier Acres prototype as separate work. This is the entrant-supplied project timeline; the source publication record is described below.

The application includes property research, independent Modeling and Underwriting, editable plans, IFC and scan tools, Pascal integration, a Blender worker, interactive walkthroughs, SAM selections, Muse Image illustrations, an MCP service and the public website.
