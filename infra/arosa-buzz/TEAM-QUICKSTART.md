# Arosa agents

Open the Arosa community at `witharosa.communities.buzz.xyz`.

- **ArosAI** handles the Arosa application and coding work. Type normally in `#arosai`.
- **Fizz (Arosa)** helps turn ideas into plans and practical next steps. Type normally in `#fizz`.
- **Honey (Arosa)** helps with writing, summaries, and communication. Type normally in `#honey`.
- **Pollen (Arosa)** helps with research and analysis. Type normally in `#pollen`.

In `#general` or `#start-here`, select the shared agent from the @ picker. The shared versions include “(Arosa)” in their name, except ArosAI. They need no personal API key, model configuration, or Codex login. They all use the company's 6.1 Sol / medium setup. Start a new thread for a different task.

## Your own agent

You can also create an agent that runs through your own connected Codex:

1. Open Agents and duplicate a shared “Codex template” for Fizz, Honey, or Pollen. Give your copy a name and edit its instructions. You can also create a new agent or edit your existing Fizz.
2. Select **Codex** as the runtime/harness. Keep the runtime consistent when cloning a template.
3. Complete Codex's ChatGPT sign-in if it is not already connected. You do not need to supply an OpenAI API key for this route.
4. Select the desired available model, use medium reasoning, and save. Add the agent to a channel and select it from the @ picker.

Your personal agent uses your own Codex connection and runs on your machine. The shared “(Arosa)” agents run on the company server and remain available when your computer is off. If a personal Fizz asks for a provider/model, it has not been switched to the Codex runtime yet; use the shared Fizz while setting it up.

Your Buzz identity and your Arosa email account are separate. Keep private keys, passwords, and recovery backups out of channels.
